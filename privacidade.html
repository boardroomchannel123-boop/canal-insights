Política de Privacidade

Canal Insights · atualizada em 17 de outubro de 2026

Quem usa

O Canal Insights é uma ferramenta pessoal usada apenas pelo dono do canal do YouTube Boardroom Forensics, no próprio computador. Não há outros usuários, cadastro ou servidor do app na internet.

Quais dados o app acessa

Com o consentimento dado na tela do Google, o app lê, em modo somente leitura, os dados do próprio canal: informações dos vídeos e métricas do YouTube Data API e do YouTube Analytics/Reporting API (visualizações, tempo assistido, retenção, inscritos, impressões e CTR). Escopos: youtube.readonly e yt-analytics.readonly.

Como os dados são usados

Exclusivamente para mostrar gráficos e análises do desempenho do canal ao próprio dono, num painel local. O app não publica, não altera e não apaga nada no YouTube.

Onde ficam e com quem são compartilhados

Os dados ficam guardados apenas no computador do dono do canal (banco de dados local). A autorização do Google (token de atualização) fica no Keychain do macOS. Nenhum dado é vendido, compartilhado, enviado a terceiros ou usado para publicidade.

Uso de dados das APIs do Google

O uso e a transferência das informações recebidas das APIs do Google seguem a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado. O app também está sujeito aos Termos de Serviço do YouTube e à Política de Privacidade do Google.

Como revogar o acesso e apagar os dados

O acesso pode ser revogado a qualquer momento em myaccount.google.com/permissions. Os dados locais são apagados ao remover a pasta de dados do app no computador.

Contato

Pelo e-mail de suporte informado na tela de consentimento do Google.

Summary in English

Canal Insights is used only by the owner of the Boardroom Forensics YouTube channel, on their own computer. With consent, it reads the channel's own YouTube Data and Analytics data with read-only scopes (youtube.readonly, yt-analytics.readonly) solely to display a private local dashboard. Data stays on the owner's computer; the OAuth token is stored in the macOS Keychain; nothing is sold, shared or sent to third parties. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Access can be revoked at any time at myaccount.google.com/permissions.
